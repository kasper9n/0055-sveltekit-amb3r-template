# SvelteKit Amb3r Template

- **SvelteKit**
- **Uikit**
- **Global SCSS file**
- **`smooth-scrollbar.js`** (https://idiotwu.github.io/smooth-scrollbar/)
- **NProgress**

## Dev instructions

### Get started

1. Install Node.js
2. Run `npm install`

### Commands

Start app in dev mode
```
npm run dev
```

Build the app. **Before you build for production, make sure to use the appropriate [adapter](https://kit.svelte.dev/docs#adapters) for your target environment. Currently, `@sveltejs/adapter-static` is used**
```
npm run build
```

Preview production site

```
npm run preview
```
